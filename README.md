# Project MangaX คืออะไร

 MangaX เป็นเว็บอ่านมังงะที่มีองค์ประกอบเป็นภาพเคลื่อนไหวบางฉากเพื่อความสนุก

> หมายเหตุ: โปรเจคนี้ทำขึ้นเพื่อการศึกษาไม่ได้ใช้งานในเชิงพาณิชย์

### Build setup : ติดตั้ง Client

``` bash
#cd เข้า folder client
cd client

#ติดตั้ง dependency
npm install

#รัน project
ืnpm run dev

```


### Build setup : ติดตั้ง Server

``` bash
#cd เข้า folder client
cd server

#ติดตั้ง dependency
npm install

#รัน project
nodemon server.js

```
